# 🛍️ ShopEase – React E-Commerce UI

A modern and responsive E-Commerce User Interface built using **React.js, JavaScript, HTML, and CSS**.

## 🚀 Project Overview

ShopEase is a responsive online shopping UI that displays a collection of products with images, prices, and an Add to Cart feature. It provides a clean and user-friendly shopping experience across desktop, tablet, and mobile devices.

## ✨ Features

- 🏠 Responsive navigation header
- 🎨 Attractive promotional banner
- 🛒 Product listing using React `.map()`
- 🖼️ Product images and details
- 💰 Product prices in Indian Rupees (₹)
- ➕ Add to Cart functionality
- 🔢 Dynamic cart item count using React State
- 📱 Mobile-friendly responsive design
- 🔤 Open Sans Google Font

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Google Fonts

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/JayaJavaDev/React-UI-Project.git
```

**2. Navigate to the project folder**

```bash
cd React-UI-Project
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in browser**

```text
http://localhost:5173/
```
